# 스토어 등록 문구

App Store Connect · Google Play Console에 그대로 붙여 넣는 문구. 칸마다 글자 수 제한이 있어서 칸별로 나눠 두었다.

- 아직 없는 기능(알림 · 백업 · 화면 모드)은 적지 않는다. 생기면 여기와 `docs/RELEASE_NOTES.md`를 같이 고친다.
- 스토어 칸에는 **이모지를 쓰지 않는다.** (Apple은 일부 칸에서 거부하고, Google은 이름 · 간단한 설명의 이모지를 정책상 막는다) 꾸밈은 `[ ]` 제목과 `•` 목록으로 한다.
- 글자 수는 공백 포함. 고친 뒤 아래 "글자 수 확인" 명령으로 센다.

[한 해의 마음 흐름을 통계로]

## 글자 수 확인

```powershell
# 이 문서의 칸(``` 블록)마다 글자 수를 센다
$t = Get-Content docs\STORE_LISTING.md -Raw -Encoding UTF8
[regex]::Matches($t, '###\s+(.+?)\r?\n(?:[^\n`]*\n)?```\r?\n([\s\S]*?)\r?\n```') | ForEach-Object { '{0,5}자  {1}' -f $_.Groups[2].Value.Replace("`r",'').Length, $_.Groups[1].Value }
```
