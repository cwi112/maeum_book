# 엑셀 내보내기 기획안

> 상태: **1차 구현 완료** (2026-11-26, 설정 › 데이터 › 엑셀로 내보내기). 2차(기간 선택) · 3차(가져오기)는 아직.
>
> 구현하면서 바꾼 것: `excel` 패키지 대신 **xlsx를 직접 만든다** (`lib/core/utils/xlsx_writer.dart`). 함수와 계산값을 함께 넣어 미리보기에서도 숫자가 보이고, 머리글 고정 · 자동 필터도 넣었다. 패키지는 `archive`(zip) · `share_plus`(공유) · `file_picker`(저장 위치 고르기) · `path_provider`(임시 폴더).
>
> 2026-11-26 보강: ① 읽기 좋은 서식 ② 샘플 데이터도 내보내기(테스트용, 임시) ③ 저장 위치 논의 ④ 합계 · 통계를 **엑셀 함수**로

## 1. 목표

앱에 쌓인 경조사 기록을 **엑셀(.xlsx) 파일 하나로 꺼내** 카톡 · 메일 · 파일 앱으로 보내거나 PC에서 열어 볼 수 있게 한다.
부모님 세대처럼 엑셀로 장부를 정리하던 사람이 "앱에 넣어도 언제든 꺼낼 수 있다"고 안심하게 하는 기능. (README의 핵심 기능)

## 2. 비용

### 돈: **0원**

| 항목 | 비용 | 이유 |
| --- | --- | --- |
| 엑셀 만드는 패키지 [`excel`](https://pub.dev/packages/excel) 4.0.6 | 무료 | MIT 라이선스 (상업 앱에도 무료) |
| 파일 공유 패키지 [`share_plus`](https://pub.dev/packages/share_plus) 13.3.1 | 무료 | BSD-3 라이선스 |
| 서버 (Supabase) | 0원 | **파일을 휴대폰 안에서 만든다.** 회원도 기기 사본(서버와 같은 내용)에서 읽으므로 서버 요청 · 저장 공간을 쓰지 않음 |
| 파일 보관 | 0원 | 서버에 올리지 않는다 (아래 5. 저장 위치) |
| 쓰지 않을 것 | — | `syncfusion_flutter_xlsio`: 상업 라이선스 또는 조건부 무료(커뮤니티) 라이선스 등록이 필요해서 제외 |

### 개발 시간 (예상)

| 단계 | 내용 | 예상 |
| --- | --- | --- |
| 1차 (MVP) | 시트 4개 + **서식 · 함수** + 샘플 내보내기 + 공유 창 / 기기에 저장 + 테스트 | **2 ~ 3일** |
| 2차 | 기간 선택(올해 · 작년 · 직접), 보냄/받음만 골라 내보내기 | +0.5 ~ 1일 |
| 3차 (선택) | 엑셀 → 앱 **가져오기** (양식 검사 · 중복 처리 · 회원 서버 반영) | +3 ~ 5일 (별도 기획 필요) |

### 그 밖의 비용 · 위험

- **앱 용량**: 패키지 2개로 약 0.5 ~ 1MB 늘어남 (예상치)
- **`excel` 패키지 최근 업데이트가 2년 전**: 오래 관리되지 않을 위험.
- **`excel` 패키지로 되는 것 / 안 되는 것** (4.0.6 문서 확인)

  | 기능 | 지원 | 쓰는 곳 |
  | --- | --- | --- |
  | 함수 (`FormulaCellValue('SUM(E3:E40)')`) | ✅ | 합계 · 소계 · 사람별 합계 |
  | 굵게 · 글자색 · 배경색 · 테두리 · 정렬 · 줄바꿈 (`CellStyle`) | ✅ | 머리글 · 소계 · 금액 |
  | 숫자 형식 `#,##0` / 날짜 형식 `yyyy-mm-dd` | ✅ | 금액 · 날짜 칸 |
  | 칸 합치기 (`merge`) | ✅ | 시트 맨 위 제목 |
  | 열 너비 · 행 높이 직접 지정 | ✅ | (자동 맞춤은 믿기 어려워 직접 지정) |
  | 틀 고정(머리글 고정) · 자동 필터 · 조건부 서식 | ❌ | — |

- **⚠️ 함수 결과가 휴대폰 미리보기에서 빈칸으로 보일 위험**: 이 패키지는 함수만 쓰고 **계산된 값은 넣지 않는다.**
  PC 엑셀 · 구글 시트 · 휴대폰 엑셀 앱은 열 때 다시 계산하지만, **아이폰 파일 미리보기 · 카톡 미리보기처럼 계산을 안 하는 뷰어는 0이나 빈칸**으로 보일 수 있다.
  → 구현 첫날 실제 기기(아이폰 미리보기 · 카톡 · 엑셀 앱 · 구글 시트)에서 확인한다.
  → 문제가 있으면 **xlsx를 직접 만드는 방식**으로 바꾼다. (xlsx = XML 파일 몇 개를 zip으로 묶은 것) 함수와 계산된 값을 함께 넣을 수 있고, 덤으로 **틀 고정 · 자동 필터도 가능**해진다. (+0.5 ~ 1일)
- **iPad**: 공유 창이 말풍선(popover)으로 떠서 누른 버튼 위치를 넘겨야 한다 (`sharePositionOrigin`). 빠뜨리면 iPad에서 오류 · 심사 반려 가능.

## 3. 1차 범위 (제안)

### 진입
설정 › 데이터 › **엑셀로 내보내기** → (기록이 없으면 "내보낼 기록이 없어요") → 파일 만들기 → **저장 방법 고르기** (5. 저장 위치)

### 파일
- 이름: `마음장부_2026-11-26.xlsx` (내보낸 날짜)
- 샘플 둘러보기 중이면 `마음장부_샘플_2026-11-26.xlsx` (아래 4. 샘플 데이터)

### 시트 구성

모든 시트 공통: 1행 = 시트 제목(칸 합치기), 2행 = 내보낸 날짜, 3행 = 머리글, 4행부터 데이터.

**① 요약** — 숫자는 모두 다른 시트를 가리키는 **함수**라, 엑셀에서 기록을 고치면 요약도 함께 바뀐다.

| 항목 | 값 (함수) |
| --- | --- |
| 보낸 마음 합계 | `=SUM('보낸 마음'!E4:E43)` |
| 보낸 건수 | `=COUNT('보낸 마음'!E4:E43)` |
| 받은 마음 합계 | `=SUMIF('받은 마음'!A4:A60,"<>소계*",'받은 마음'!F4:F60)` (소계 줄은 빼고) |
| 받은 건수 | `=COUNTIFS('받은 마음'!A4:A60,"<>소계*",'받은 마음'!F4:F60,">0")` |
| 차액 (받은 - 보낸) | `=B6-B4` |
| 평균 (보낸 1건) | `=IFERROR(B4/B5,0)` |
| 가장 큰 금액 (보낸) | `=MAX('보낸 마음'!E4:E43)` |
| 기간 | `=MIN(...)` ~ `=MAX(...)` (날짜 칸) |

아래에 **종류별 합계 표** (결혼 · 장례 · 돌 …): `=SUMIF('보낸 마음'!B4:B43,"결혼",'보낸 마음'!E4:E43)` 처럼 보낸 · 받은 두 열.
그리고 **연도별 합계 표**: `=SUMPRODUCT((YEAR('보낸 마음'!A4:A43)=2025)*'보낸 마음'!E4:E43)`

**② 보낸 마음** — 최신순

| 날짜 | 종류 | 이름 | 관계 | 금액 | 메모 |
| --- | --- | --- | --- | --- | --- |
| 2026-11-20 | 결혼 | 김민준 | 친구 | 100,000 | 대학 동기 |
| … | | | | | |
| **합계** | | | | **`=SUM(E4:E43)`** | |

**③ 받은 마음** — 행사별로 묶고, 행사마다 소계

| 행사 | 행사 날짜 | 종류 | 이름 | 관계 | 금액 | 메모 |
| --- | --- | --- | --- | --- | --- | --- |
| 우리 결혼식 | 2025-03-16 | 결혼 | 한지민 | 친구 | 400,000 | |
| … | | | | | | |
| **소계 · 우리 결혼식** | | | | **`=COUNT(F4:F15)`명** | **`=SUM(F4:F15)`** | |
| **총합계** | | | | | **`=SUMIF(A4:A60,"<>소계*",F4:F60)`** | |

**④ 사람별** — 다음 경조사 때 얼마 할지 참고용. 합계는 함수로 계산한다.

| 이름 | 관계 | 보낸 합계 | 받은 합계 | 차액 | 마지막 날짜 |
| --- | --- | --- | --- | --- | --- |
| 김민준 | 친구 | `=SUMIFS('보낸 마음'!E:E,'보낸 마음'!C:C,A4,'보낸 마음'!D:D,B4)` | `=SUMIFS('받은 마음'!F:F, …)` | `=D4-C4` | 앱이 계산한 값 |

- 이름 · 관계 목록과 "마지막 날짜"는 앱이 값으로 넣는다. (MAXIFS는 엑셀 2019 이상에서만 돼서 쓰지 않음)

### 서식 (읽기 좋게)

| 대상 | 서식 |
| --- | --- |
| 시트 제목 (1행) | 칸 합치기 · 굵게 · 14pt · 테라코타 글자 |
| 머리글 (3행) | 굵게 · 연한 테라코타 배경 `#F6E7DE` · 가운데 정렬 · 아래 테두리 |
| 데이터 줄 | 한 줄 건너 아주 연한 배경(줄무늬) · 얇은 회색 테두리 |
| 금액 | **숫자 칸** + `#,##0` · 오른쪽 정렬 (엑셀에서 바로 정렬 · 계산 가능) |
| 날짜 | **날짜 칸** + `yyyy-mm-dd` · 가운데 정렬 (글자가 아니라서 정렬 · 필터 됨) |
| 차액 | 받은 게 많으면 초록, 보낸 게 많으면 테라코타 글자 (앱이 값을 보고 색을 정함 · 조건부 서식은 미지원) |
| 소계 · 합계 줄 | 굵게 · 연한 회색 배경 · 위 테두리 |
| 메모 | 줄바꿈 켬 · 넓은 열 |
| 열 너비 | 날짜 12 · 종류 8 · 이름 12 · 관계 8 · 금액 14 · 메모 30 (직접 지정) |
| 글꼴 | 맑은 고딕 (엑셀 기본 한글 글꼴) |

- 관계 · 종류는 한글 이름으로 (family → 가족)
- 함수 안의 시트 이름은 띄어쓰기가 있어서 작은따옴표로 감싼다: `'보낸 마음'!E4`

## 4. 샘플 데이터 내보내기 (테스트용, 임시)

- 설정 › 샘플 둘러보기 중에도 엑셀로 내보내기를 **그대로 쓸 수 있게** 한다. 샘플 기록(40건 + 45건)으로 서식 · 함수를 바로 확인할 수 있다.
- 파일 이름에 `샘플`, 요약 시트 맨 위에 **"샘플 데이터예요 (실제 장부 아님)"** 를 빨간 글자로 표시한다.
- 샘플은 메모리에만 있으므로 파일을 만들어도 서버 · 기기 DB에 아무것도 남지 않는다. (만든 파일만 고른 곳에 저장됨)
- **임시**: 정식 출시 때 샘플 내보내기를 남길지 다시 정한다. 남기지 않으면 버튼 하나만 숨기면 된다. (코드는 같은 내보내기 기능을 쓰므로 따로 지울 것 없음)
- 개발 중에는 테스트가 샘플 데이터로 만든 파일을 `build/excel_sample.xlsx`로 저장하게 해서, PC 엑셀에서 바로 열어 서식 · 함수를 확인한다. (스토어 스크린샷을 테스트로 만드는 것과 같은 방식)

## 5. 저장 위치 (논의 필요)

| 방법 | 어떻게 | 장점 | 단점 |
| --- | --- | --- | --- |
| **A. 공유 창** | 파일을 만들어 기기 임시 폴더에 두고 공유 창을 띄움 → 카톡 · 메일 · "파일에 저장" · 구글 드라이브 … | 권한 필요 없음. 사용자가 원하는 곳을 고름. 아이폰 · 안드로이드 같은 코드 | "그래서 어디 저장됐지?"를 사용자가 직접 골라야 함 |
| **B. 기기에 바로 저장** | iOS: **파일 앱 › 나의 iPhone › 마음장부** 폴더 (설정 2줄만 추가) / Android: **다운로드 폴더** 또는 저장 위치 고르기 창 | 한 번 누르면 끝. 나중에 파일 앱에서 다시 찾기 쉬움 | Android 버전마다 방법이 달라 손이 더 감 (+0.5일) |
| C. 서버에 보관 후 링크 | Supabase Storage에 올리고 링크 공유 | 다른 기기에서 받기 쉬움 | **저장 · 전송 비용**, 개인정보 파일이 서버에 남음 → **안 함** |

**제안: A + B 둘 다.** 내보내기를 누르면 아래에서 두 버튼이 올라온다.

```
┌──────────────────────────────┐
│  마음장부_2026-11-26.xlsx     │
│  보낸 40건 · 받은 45건        │
│                              │
│  [ 공유하기 (카톡 · 메일) ]   │
│  [ 내 휴대폰에 저장 ]         │
└──────────────────────────────┘
```

- 저장이 끝나면 "파일 앱 › 마음장부에 저장했어요" / "다운로드 폴더에 저장했어요" 토스트.
- 공유 창용 임시 파일은 다음 내보내기 때 지운다. (기기 공간이 쌓이지 않게)

## 7. 정해야 할 것 (협의)

| # | 질문 | 제안 |
| --- | --- | --- |
| 1 | 사람별 시트: 이름이 같은 다른 사람이 한 줄로 합쳐지는 문제 | **이름 + 관계**로 묶어 같은 이름이라도 관계가 다르면 나눈다 |
| 2 | 받은 마음을 행사마다 시트로 나눌까, 한 시트에 모을까 | 한 시트 + 행사별 소계 (행사가 많아도 시트가 늘지 않게) |
| 3 | 1차에 기간 선택을 넣을까 | 1차는 **전체**만, 2차에 기간 선택 |

| 5 | 내보내기 위치 | 설정 › 데이터 + 나중에 통계 화면 오른쪽 위 버튼 |
| 6 | CSV도 같이 줄까 | 안 줌 (.xlsx 하나로) |
| 7 | **저장 위치** | 공유 창 + 내 휴대폰에 저장 둘 다 (5번 표) |
| 8 | **함수가 미리보기에서 빈칸이면** | xlsx 직접 만들기로 전환 (함수 + 계산값 + 틀 고정 · 필터까지) |
| 9 | **샘플 내보내기를 정식 출시에도 남길까** | 개발 · 테스트 동안만 (임시) |

## 8. 구현 메모 (구현할 때)

- 구조: `ExcelExporter`(기록 → 바이트, 순수 함수 · 테스트 쉬움) + `ExportFileService`(바이트 → 공유 창 / 기기에 저장). 화면은 ViewModel 한 메서드만 부른다.
- 서식은 `ExcelStyles` 한 곳에 모아 둔다 (앱의 AppColors처럼). 시트마다 같은 머리글 · 소계 서식을 재사용.
- 함수 범위(E4:E43)는 데이터 줄 수로 계산해서 넣는다. 데이터가 0건이면 함수 대신 0.
- 테스트: 만든 바이트를 `Excel.decodeBytes`로 다시 읽어 시트 이름 · 머리글 · **함수 문자열** · 날짜 칸 확인. 큰 금액(1억 × 수백 건)도 확인.
- 개인정보: 파일은 사용자가 고른 곳으로만 나간다. 앱이 서버에 올리지 않는다.
