# 엑셀 내보내기 기획안

> 상태: **기획 단계** (설정 › 준비 중 › 엑셀로 내보내기 = "곧 추가될 기능" 안내만). 이 문서로 범위를 정한 뒤 구현한다.

## 1. 목표

앱에 쌓인 경조사 기록을 **엑셀(.xlsx) 파일 하나로 꺼내** 카톡 · 메일 · 파일 앱으로 보내거나 PC에서 열어 볼 수 있게 한다.
부모님 세대처럼 엑셀로 장부를 정리하던 사람이 "앱에 넣어도 언제든 꺼낼 수 있다"고 안심하게 하는 기능. (README의 핵심 기능)

## 2. 비용

### 돈: **0원**

| 항목 | 비용 | 이유 |
| --- | --- | --- |
| 엑셀 만드는 패키지 [`excel`](https://pub.dev/packages/excel) 4.0.6 | 무료 | MIT 라이선스 (상업 앱에도 무료) |
| 파일 공유 패키지 [`share_plus`](https://pub.dev/packages/share_plus) 13.3.1 | 무료 | BSD-3 라이선스 |
| 서버 (Supabase) | 0원 | **파일을 휴대폰 안에서 만든다.** 회원도 기기 사본(서버와 같은 내용)에서 읽으므로 서버 요청 · 저장 공간을 쓰지 않음 |
| 파일 보관 | 0원 | 서버에 올리지 않고 공유 창으로 바로 넘김 (임시 파일은 기기 임시 폴더) |
| 쓰지 않을 것 | — | `syncfusion_flutter_xlsio`: 상업 라이선스 또는 조건부 무료(커뮤니티) 라이선스 등록이 필요해서 제외 |

### 개발 시간 (예상)

| 단계 | 내용 | 예상 |
| --- | --- | --- |
| 1차 (MVP) | 전체 기록 → 시트 4개(요약 · 보낸 · 받은 · 사람별), 숫자 · 날짜 형식, 공유 창, 설정 메뉴 연결, 테스트 | **1.5 ~ 2일** |
| 2차 | 기간 선택(올해 · 작년 · 직접), 보냄/받음만 골라 내보내기 | +0.5 ~ 1일 |
| 3차 (선택) | 엑셀 → 앱 **가져오기** (양식 검사 · 중복 처리 · 회원 서버 반영) | +3 ~ 5일 (별도 기획 필요) |

### 그 밖의 비용 · 위험

- **앱 용량**: 패키지 2개로 약 0.5 ~ 1MB 늘어남 (예상치)
- **`excel` 패키지 최근 업데이트가 2년 전**: 기능은 충분하지만 오래 관리되지 않을 위험. 막히면 대안 — xlsx는 "XML 파일 몇 개를 zip으로 묶은 것"이라 직접 만들 수 있다(이미 쓰는 `archive` 계열로 0.5일 추가).
- **`excel`이 문서에 없는 것**: 첫 줄 고정(틀 고정), 수식 쓰기. → 1차에서는 수식 대신 **합계를 앱이 계산해 값으로** 넣는다.
- **iPad**: 공유 창이 말풍선(popover)으로 떠서 누른 버튼 위치를 넘겨야 한다 (`sharePositionOrigin`). 빠뜨리면 iPad에서 오류 · 심사 반려 가능.

## 3. 1차 범위 (제안)

### 진입
설정 › 데이터 › **엑셀로 내보내기** → (기록이 없으면 "내보낼 기록이 없어요") → 파일 만들기 → **공유 창** (카톡 · 메일 · 파일에 저장 · AirDrop …)

### 파일
- 이름: `마음장부_2026-11-26.xlsx` (내보낸 날짜)
- 샘플 둘러보기 중이면 `마음장부_샘플_2026-11-26.xlsx` + 요약 시트에 "샘플 데이터" 표시 (실제 장부와 헷갈리지 않게)

### 시트 구성

**① 요약**
| 항목 | 값 |
| --- | --- |
| 내보낸 날짜 | 2026-11-26 |
| 보낸 마음 | 4,710,000원 (40건) |
| 받은 마음 | 4,190,000원 (45건) |
| 차액 (받은 - 보낸) | -520,000원 |
| 기간 | 2024-12-01 ~ 2026-11-20 |

**② 보낸 마음** — 최신순
| 날짜 | 종류 | 이름 | 관계 | 금액 | 메모 |
| --- | --- | --- | --- | --- | --- |

**③ 받은 마음** — 행사별로 묶고 행사마다 소계
| 행사 | 행사 날짜 | 종류 | 이름 | 관계 | 금액 | 메모 |
| --- | --- | --- | --- | --- | --- | --- |
| 우리 결혼식 | 2025-03-16 | 결혼 | 한지민 | 친구 | 400,000 | |
| | | | | **소계 12명** | **1,450,000** | |

**④ 사람별** — 주고받은 합계 (다음 경조사 때 얼마 할지 참고용)
| 이름 | 관계 | 보낸 합계 | 받은 합계 | 차액 | 마지막 날짜 |
| --- | --- | --- | --- | --- | --- |

### 형식
- 금액: **숫자 칸** + 천 단위 쉼표(`#,##0`) → 엑셀에서 바로 정렬 · 합계 가능
- 날짜: **날짜 칸** (글자가 아니라서 엑셀 필터 · 정렬이 됨)
- 머리글: 굵게 + 연한 테라코타 배경, 열 너비 자동
- 관계 · 종류는 한글 이름으로 (family → 가족)

### 회원 · 비회원
| 상태 | 무엇을 내보내나 | 인터넷 |
| --- | --- | --- |
| 비회원 | 이 기기의 기록 | 필요 없음 |
| 회원 | 이 기기에 받아 둔 계정 사본 (= 서버와 같음) | 필요 없음. 단, 인터넷이 끊겨 최신을 못 받았으면 "마지막으로 받아 온 기록 기준" 안내 |
| 샘플 둘러보기 | 샘플 기록 (파일 이름에 "샘플") | 필요 없음 |

## 4. 정해야 할 것 (협의)

| # | 질문 | 제안 |
| --- | --- | --- |
| 1 | 사람별 시트를 넣을까? 이름이 같은 다른 사람이 한 줄로 합쳐지는 문제 | 넣는다. **이름 + 관계**로 묶어 같은 이름이라도 관계가 다르면 나눈다 |
| 2 | 받은 마음을 행사마다 시트로 나눌까, 한 시트에 모을까 | 한 시트 + 행사별 소계 (행사가 많아도 시트가 늘지 않게) |
| 3 | 1차에 기간 선택을 넣을까 | 1차는 **전체**만, 2차에 기간 선택 |
| 4 | 엑셀 → 앱 가져오기가 필요할까 | 별도 기획 (양식 · 중복 · 회원 서버 반영이 커서 1차 제외) |
| 5 | 내보내기 위치 | 설정 › 데이터에 두고, 나중에 통계 화면 오른쪽 위에도 버튼 |
| 6 | CSV도 같이 줄까 | 안 줌 (엑셀에서 한글이 깨지는 문제가 잦음, .xlsx 하나로) |

## 5. 구현 메모 (구현할 때)

- 구조: `ExcelExporter`(기록 → 바이트, 순수 함수 · 테스트 쉬움) + `ShareService`(바이트 → 임시 파일 → 공유 창). 화면은 ViewModel 한 메서드만 부른다.
- 테스트: 만든 바이트를 `Excel.decodeBytes`로 다시 읽어 시트 이름 · 머리글 · 합계 · 날짜 칸 확인. 큰 금액(1억 × 수백 건)도 확인.
- 개인정보: 파일은 사용자가 고른 곳으로만 나간다. 앱이 서버에 올리지 않는다.
