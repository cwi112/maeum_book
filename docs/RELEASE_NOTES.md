## 1.2.2 · 2026년 11월

### 🛠 고쳤어요
- 앨범에서 사진을 넣었는데 바로 보이지 않고, 다음에 넣을 때 두 장이 한꺼번에 나타나던 문제
- 저장하는 사이 장부를 새로 받아 오면 방금 저장한 기록이 잠깐 사라지던 문제
- 버튼을 빠르게 두 번 누르면 같은 화면이 두 번 열리던 문제

### ✨ 달라졌어요
- 이름이 같아도 관계가 다르면 통계에서 다른 사람으로 나눠 보여요.
- 화환 사진이 있는 분의 기록을 지우면, 확인한 뒤 사진도 함께 지워요.
- 앱을 켤 때 로고 화면을 잠깐(1초) 보여 줘요.
- 사진 보기 화면의 장 수 표시가 더 잘 보여요. 통계 그래프 밖을 누르면 선택이 풀려요.
- 설정 › 정보에서 개인정보 처리방침을 볼 수 있어요.

## 1.2.0 · 2026년 11월

**화환 사진도 남기고, 장부는 엑셀로 꺼내요** 📸📊

### ✨ 새로워졌어요
- **화환 · 꽃 사진** — 받아요 › 행사에서 화환 사진을 찍거나 앨범에서 골라 남겨요. 사진마다 보낸 분을 적으면 목록에 꽃 표시가 붙어요.
- **엑셀로 내보내기** — 설정 › 데이터에서 요약 · 보낸 마음 · 받은 마음 · 사람별 4개 시트로 된 엑셀 파일을 만들어요. 합계는 엑셀 함수로 들어 있어서 엑셀에서 고치면 다시 계산돼요. 카톡 · 메일로 공유하거나 휴대폰에 저장할 수 있어요.
- **화면 모드 · 알림 · 백업 메뉴** — 곧 추가될 기능을 설정에서 미리 볼 수 있어요.

### 🛠 고쳤어요
- 빠진 칸이 화면 밖에 있으면 기록하기 버튼이 안 눌리는 것처럼 보이던 문제 → 빠진 칸으로 바로 이동하고 커서를 놓아 드려요.
- 저장 · 삭제 중에는 다른 곳이 눌리지 않고, 오래 걸리면 진행 중임을 보여 드려요. 연결이 너무 느리면 요청을 끊고 알려 드려요.
- 금액이 아주 커도 화면이 넘치지 않아요.
- 하단 탭을 길게 눌러도 말풍선이 뜨지 않고, 지금 탭을 다시 눌러도 깜빡이지 않아요.
- 카드를 누를 때 물결이 둥근 모서리 밖으로 나가지 않아요.

## 1.1.0 · 2026년 11월

**어느 기기에서든, 내 장부를 이어서** 💌

### ✨ 새로워졌어요
- **카카오 · Apple 로그인** — 로그인하면 기록이 안전하게 보관되고, 휴대폰을 바꾸거나 앱을 다시 깔아도 그대로 이어서 쓸 수 있어요.
- **기존 기록 옮기기** — 로그인 전에 쓰던 기록이 있으면 처음 로그인할 때 계정으로 옮길지 물어봐요.
- **로그인 없이 시작하기** — 로그인하지 않아도 모든 기록 기능을 쓸 수 있어요. (이 기기에만 저장돼요)
- **카카오 ↔ Apple 계정 연결** — 설정에서 연결해 두면 어느 쪽으로 로그인해도 같은 장부예요.
- **샘플 데이터로 둘러보기** — 예시 기록으로 화면과 통계를 미리 볼 수 있어요. 내 기록과 섞이지 않고, 앱을 끄면 사라져요.
- **최신 버전 확인** — 설정 › 앱 정보를 누르면 새 버전이 있는지 알려 줘요.
- **시작 화면** — 앱을 켤 때 마음장부 로고가 반겨 줘요.

### 🛠 고쳤어요
- 받아요 목록을 내린 채로 기록을 모두 지우면 위쪽 그림자가 남고 행사 만들기 버튼이 사라지던 문제
- 인터넷이 끊기거나 불안정하면 한 번만 알려 드려요. (회원은 인터넷이 연결돼야 저장할 수 있어요)
